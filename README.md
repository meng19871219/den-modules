# den-modules

DenPlayer 自定义模块合集（自用）

## 当前模块

### 黄果接口适配

- 文件：`widgets/huangguo.js`
- 版本：1.0.1
- 说明：连接自行配置的兼容接口，支持热门 / 最新 / 排行榜 / 短剧 / 漫剧 / 搜索，按需解析播放地址。

**Raw 导入链接：**

```
https://raw.githubusercontent.com/meng19871219/den-modules/main/widgets/huangguo.js
```

## 使用方法

1. 打开 DenPlayer → 设置 → 模块 → 右上角「添加」→「通过链接添加」
2. 粘贴上面的 Raw 链接
3. 安装后进入模块配置，填写你的 **服务 API 地址**（以及可选的封面代理和 Token）
4. 点击「检查连接」验证通过后即可使用

## 注意事项

- 本仓库仅存放适配脚本，不提供任何内容服务或密钥
- 请自行准备符合接口规范的后端服务
